# e-plantShopping

## Project Details
**Project name:** e-plantShopping  
**Application name:** Paradise Nursery Shopping Application

## Description
 e-plantShopping is a React-based plant shopping application for browsing plants, adding plants to a Redux-powered shopping cart, updating quantities, deleting products, and calculating order totals.

## Technologies Used
- React
- Vite
- JavaScript
- Redux Toolkit
- React Redux
- CSS

## Features
- Landing page with the heading “Welcome to Paradise Nursery” and a “Get Started” button
- About Us section with company details
- Three plant categories with at least six unique plants per category
- Plant thumbnails, names, and prices
- Add to Cart button for each plant
- Add to Cart button is disabled after the plant is added
- Navigation between Home, Plants, and Cart
- Dynamic cart quantity indicator
- Shopping cart with image, name, unit price, and line total
- Increase and decrease quantity controls
- Delete item functionality
- Dynamic total cost calculation
- Checkout button showing a “Coming Soon” message
- Continue Shopping button to return to the plant listing

## Run the Application
1. Install Node.js.
2. Open a terminal in this project directory.
3. Install dependencies using `npm install`.
4. Start the development server using `npm run dev`.
5. Open the local URL shown in the terminal.
