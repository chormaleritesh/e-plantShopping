# e-plantShopping

## Project Name
e-plantShopping — Paradise Nursery Shopping Application

## Description
Paradise Nursery is a React-based plant shopping application that allows customers to explore plants, browse different categories, add plants to a shopping cart, adjust quantities, remove items, and view the total cost of their selected products.

## Features
- Attractive landing page with a background image.
- Company information section.
- Plant categories: Indoor Plants, Outdoor Plants, and Herbs.
- Product images, descriptions, and prices.
- Add-to-cart functionality using Redux Toolkit.
- Dynamic cart quantity indicator.
- Increase and decrease item quantities.
- Remove products from the shopping cart.
- Automatic subtotal and total-cost calculations.
- Responsive design for desktop and mobile devices.

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite
